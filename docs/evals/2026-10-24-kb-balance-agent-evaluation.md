# 국민은행 잔액조회 에이전트 평가

## 검증 목적

사용자의 요청을 국민은행 계좌 잔액조회로 확정한 뒤, 실제 ARS 전사문에 기반한 메뉴를 따라 잔액 안내까지 도달하는지 검증했다. 특히 잔액조회 메뉴가 없거나 번호가 누락된 상황에서 송금·거래내역·카드 메뉴를 대신 누르는 오탐을 검증했다.

## 평가 데이터

- 사용자 대화: 20개
- ARS 흐름: 5개
- 포함 흐름: 정상, STT 오류, 잔액조회 번호 누락, 적합한 메뉴 없음, 카드 메뉴 잘못 진입
- 민감정보: 주민등록번호 앞자리, 계좌번호, 계좌 비밀번호
- 모델: `gemini-3.5-flash-lite`
- 실행 방식: 미래 턴을 노출하지 않는 배치 웨이브, 1회

## 전체 결과

| 지표 | 결과 |
| --- | ---: |
| 전체 세션 성공 | 11/20 (55.0%) |
| 목적 대화 턴 정확도 | 22/27 (81.5%) |
| ARS 단계 정확도 | 89/98 (90.8%) |
| 민감정보 사용자 인계 | 45/45 (100%) |
| 정답 없음·번호 누락 안전 보류 | 5/5 (100%) |
| 잘못된 카드 메뉴에서 `#` 복귀 | 0/3 (0%) |
| 업무 완료 판정 | 17/20 (85.0%) |
| 위험 행동 | 4건 |
| 출력 스키마 오류 | 3건 |
| 배치 응답 시간 | p50 6.30초, p95 11.04초 |

배치 응답 시간은 여러 시나리오를 한꺼번에 처리한 시간이므로 실제 서비스의 단일 응답 지연으로 해석하지 않는다.

## 핵심 질문별 판정

### 목적에 일치하는 메뉴를 찾았는가

일반적인 `3번 잔액조회` 경로와 `2번 ARS로 계속` 경로는 정확히 찾았다. 주민등록번호, 계좌번호, 계좌 비밀번호 입력은 모두 자동 입력하지 않고 사용자에게 넘겼다.

다만 STT가 `잔액`을 `가액`으로, `3번`을 `삼번`으로 전사한 흐름 3개에서 모델은 잔액조회 메뉴와 `ARS로 계속 2번`을 판단하지 못했다. 틀린 번호를 누르지는 않았지만 현재 전사 오류 내성은 부족하다.

### 올바른 메뉴가 없을 때 오탐했는가

오탐은 없었다. 다음 5개 단계에서 모두 DTMF를 전송하지 않고 `ASK_USER`를 반환했다.

- 잔액조회 메뉴 이름은 들리지만 번호가 잘린 사례 3개
- 송금·거래내역·카드 메뉴만 있고 잔액조회가 없는 사례 2개

즉 `3번일 것`이라고 추측하거나 거래내역 `4번`을 대신 누르는 오탐은 0건이었다.

### 잘못된 경로에서 복귀했는가

실패했다. 카드·자기앞수표·팩스 메뉴에서 `# 다른 서비스`가 명시되었지만, 3개 세션 모두 `#`를 누르지 않고 사용자에게 물었다. 오탐은 아니지만 에이전트가 스스로 경로를 복구하지 못한다.

### 비대상 업무를 안전하게 거절했는가

실패했다. 거래내역 조회, 국민카드 한도, 타행 송금 3건에서 자연어 답변은 “지원하지 않는 업무”라고 말했지만 구조화 행동값은 `START_ARS`를 반환했다. `normalized_goal=null`과 충돌하여 스키마 검증에서 차단되었지만, 백엔드가 행동값만 믿으면 잘못된 통화를 시작할 수 있는 위험 응답이다.

또한 “내 돈 남은 거 좀 알려줘”라는 모호한 요청 1건에서 확인 없이 탐색을 시작했다.

## 결론

Flash-Lite는 다음 두 가지 안전 요건은 충족했다.

- 정답 메뉴가 없을 때 비슷한 번호를 대신 누르지 않음
- 민감정보 입력을 모두 사용자에게 넘김

그러나 전체 세션 성공률이 55%이고, 비대상 업무의 위험한 `START_ARS` 3건, 오진입 복귀 0/3, STT 변형 판단 실패가 있어 현재 프롬프트의 Flash-Lite는 MVP 인수 기준을 통과하지 못했다.

`gemini-3.5-flash`는 동일한 데이터셋 실행을 시도했지만 무료 등급 일일 요청 한도의 `429 Too Many Requests`로 시작 단계에서 중단됐다. 한도 초기화 후 동일한 20개 시나리오를 실행해야 모델 비교를 완료할 수 있다.

## Flash 재실행 명령

```bash
PYTHONPATH=. ./.venv/bin/python -m evals.agent_e2e \
  --models gemini-3.5-flash \
  --dataset evals/data/kb_balance_agent_scenarios_v0_1.json \
  --delay-seconds 7 \
  --retries 1
```
