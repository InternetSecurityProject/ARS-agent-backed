# ARS 자동화 서버 — main 대비 변경 사항

브랜치 `fix/caption-and-readback` 이 `main`(9f373e2)에 더한 변경을 정리한다. 채연 작업은 (채연)으로 표시했다.

## 1. 음성 인식(STT)

| 변경 | 내용 | 파일 |
| --- | --- | --- |
| 후보 엔진 추가 | 리턴제로(`STT=rtzr`), CLOVA Speech(`clova`), Gemini(`gemini`), Qwen3-ASR(`qwen`)를 선택할 수 있다. 외부 엔진은 실패·시간 초과(`STT_TIMEOUT_S`) 시 빈 결과를 반환하고, 필수 키가 없으면 서버 시작 시 오류를 낸다. | stt_engines.py, stt.py, .env.example |
| 외부 STT 되읽기 건너뛰기 | 외부 STT 사용 시 민감정보 입력 뒤 되읽기 구간을 외부로 전송하지 않는다. 20초(`SECURE_SKIP_S`)가 지나면 인식을 재개한다. | session.py, config.py |
| 받아쓰기+분류 1회 호출 | `STT=gemini` 이고 `GEMINI_STT_COMBINED=1` 이면 녹음 하나로 받아쓰기와 분류·점수를 Gemini 한 번에 받아 해석기 캐시에 넣는다. | stt_engines.py, gemini_interpreter.py, app.py |
| 무음 환각 제거 (채연) | Silero VAD 로 말소리 없는 구간을 잘라내고(`STT_VAD=1`), 말이 아니거나 반복·확신이 낮은 조각을 버린다. | stt.py |
| 짧은 단락 제외 | 유음 길이 0.4초(`MIN_VOICED_S`) 미만 단락은 인식하지 않는다. 인식 결과가 두 글자 이하이면 버린다. | session.py, config.py |
| STT 비교 도구 (채연 포함) | `stt_bench.py` 에 `--device`, `--models`(rtzr·clova·gemini·openai·qwen·whisper:<모델>), 요약 표를 추가했다. 시험 음성 19개(`bench_clips/`)를 저장소에 둔다. | stt_bench.py, bench_clips/ |
| 문서 | STT 무음 환각·숫자 처리 설계안, STT 후보 엔진 검증 기록을 추가하고 엣지케이스 점검표를 갱신했다. | docs/ |

## 3. 민감정보 입력·되읽기

| 변경 | 내용 | 파일 |
| --- | --- | --- |
| 되읽기 판별 강화 | 되읽기 구간이 닫힌 뒤에도 "입력하신 … 맞으면" 문장에 한국어 숫자를 여섯 자 이상 이어 읽으면 입력값 되읽기로 처리한다. 자릿수가 달라도 한국어 숫자 연속열은 가린다. 짧은 안내("잠시만 기다려 주십시오")로는 되읽기 구간을 닫지 않는다. | session.py |
| 되읽기 확인 문구 | 되읽기 확인 재질문은 숫자가 포함된 원문을 사용자에게만 보여 준다. AI 에는 가린 문장을 전달한다. | session.py |
| 되읽기 경로 표시 | 되읽기 확인 단계의 경로 이름을 "주민등록번호 확인 / 주민등록번호 재입력"처럼 입력 항목명으로 기록한다. 값은 기록하지 않는다. | session.py (`secure_label`), interpreter.py (`Prompt.readback_of`) |
| 입력 안내 반복 처리 | 입력 중 ARS 가 같은 입력 안내를 되풀이하면 새 요청을 만들지 않고 같은 `request_id` 의 만료 시각만 늘려 다시 전송한다. 입력값 전송 뒤 늦게 인식된 같은 안내는 무시한다. | session.py |
| 안내 종료 후 입력값 전송 | 입력값을 받았을 때 ARS 가 말하는 중이면("입력 시간이 초과되었습니다" 등) 안내가 끝난 뒤 전송한다. 기다리는 동안 ARS 가 메뉴·결과 등 다른 안내로 넘어가거나 15초(`SECURE_WAIT_MAX_S`) 넘게 말하면 입력값을 버리고 `input_rejected`(keys=null)를 전송한다. 대기는 잠금 밖에서 수행한다. | session.py, config.py |

## 4. 판단 (해석기·탐색)

| 점수 캐시 보완 | 분류 뒤 규칙으로 추가한 `*`·`#` 선택지가 캐시에 없어도 Gemini 를 다시 부르지 않는다 (0점 처리). | gemini_interpreter.py |

| 같은 종류 선택지 재질문 | 최고 점수 선택지와 마지막 명사가 같은 선택지가 있고(신용·체크카드 / 현금카드), 목적에 이를 가르는 말이 없으면 모델 점수가 높아도 사용자에게 묻는다 (계층당 1회). | navigator.py (`sibling_choices`) |
| 반복 판정 완화 | 확인 질문은 반복 도착으로 세지 않는다. 기준을 다시 도착 2회→3회(`MAX_REVISIT`), 키 전송 5회→10회(`MAX_PRESSES`)로 늘리고 0이면 끈다. | navigator.py, config.py |
| 무응답 시 상담원 연결 해제 | 재질문에 60초 동안 답이 없어도 상담원 연결 키를 누르지 않고 요청을 유지한 채 계속 듣는다. `CLARIFY_DROP_TO_AGENT=1` 이면 이전 동작이다. | session.py, config.py |

## 7. 웹 화면 (새 기능)

Android 앱(`feat/compose-mvp` 74d5f3c)의 상태 처리·문구·버튼 활성 조건·타이머·요청 처리 규칙을 옮긴 한 파일 웹 화면이다. 서버의 `/app` 경로로 제공하며 HTTPS 주소에서만 동작한다.

| 구분 | 내용 |
| --- | --- |
| 파일 | static/app.html (빌드 결과), web/app.src.html (원본), web/build.py (빌드), app.py (`GET /app`) |
| 빌드 | `npm pack htm@3.1.1` 후 `web/vendor` 에 풀고, `python web/build.py <ars-agent-frontend>/app/src/main/assets/figma static/app.html` |
| 진행 상태 음성 안내 | 듣는 중·선택 중 상태의 음성 안내를 생략한다. |
| 번호 입력 신호음 | 번호를 누르면 DTMF 신호음을 재생한다. |
| 목적 입력 | 데스크톱에서는 글자 입력 후 Enter 또는 '발신 확인'으로 확인 창을 연다. 휴대폰은 앱과 같이 음성 입력과 1.2초 자동 확인을 쓴다. |
| API 키 | 이 브라우저에 저장하여 다시 쓴다. '저장된 키 지우기'를 제공하며, 서버가 키를 거부하면 자동으로 지운다. |
| 통화 기록 | 발신 확인 창의 '통화 기록 남기기', 종료 화면의 '통화 기록 받기'(받은 뒤 서버 기록 삭제)·'서버 기록 지우기' |
| 민감정보 입력 칸 | 같은 `request_id` 의 재전송이면 누른 번호를 유지하고 기한만 갱신한다. |
| ARS 소리 재생 | 20ms 조각을 링 버퍼에 쌓아 연속 재생한다 (조각 경계 잡음 제거, 약 0.1초 지연). |
| 웹 환경 차이 | 오디오 출력은 스피커만 선택 가능, 뒤로가기는 브라우저 뒤로·Esc, 키보드로 번호 입력, 통화 중 페이지 닫기 경고, Firebase 업데이트 알림 없음 |
