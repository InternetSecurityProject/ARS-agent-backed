# Progress disclosures implementation plan

> **For agentic workers:** Use superpowers:executing-plans. Local execution approved; no commit/push/merge/deploy before visual review.

**Goal:** 최근 선택은 펼쳐두고 전체 이동 경로와 긴 현재 ARS 안내를 접는다.
**Architecture:** CallScreen에 통화 단위 펼침 상태를 보관하고 서버/데모 공통 표시 컴포넌트에 전달한다. 기존 API 데이터에서 마지막 선택과 가장 최근 ARS 단락만 사용한다.
**Tech Stack:** Existing Preact/htm, CSS, ResizeObserver, native details/summary, Playwright.
**Spec:** 사용자 승인: 최근 선택 항상 표시, 경로 기본 접힘(한 단계면 생략), 현재 ARS 안내 3줄 미리보기와 전문 보기, 결과/질문/개인정보/오류는 접지 않음, 안내 갱신/큰글씨 전환 시 펼침 유지.

## Constraints and review focus
- 이전 후보 글씨 16/20px 작업은 그대로 보존. 백엔드·API·음성·실제 발신·하단 버튼 위치·기존 글씨 크기 변경 없음.
- 빈 경로/한 단계/반복 단계/특수 키와 긴 문구, 최신 ARS 한 단락 선택, 상태 변경 후 중요한 결과 전체 표시를 검증한다.
- 실제 줄 수로 접힘 여부 판단: 폭·폰트·큰글씨·새 자막 변화에 재측정. 잘림 없이 3줄이며 짧은 안내에는 버튼 생략.
- native keyboard 접근, aria-expanded, 새 요청 입력 유지, 새 통화 초기화, 폰트 준비 지연과 펼침 상태 보존을 점검한다.
