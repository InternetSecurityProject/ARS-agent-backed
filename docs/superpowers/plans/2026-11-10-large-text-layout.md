# 큰글씨 정보 영역 확장

승인: 큰글씨 모드에서만 상단 모드/설정을 한 줄로 정리하고 번호·시간 위 여백 및 카드 간격을 줄인다. 기본 글씨 배치, 하단 원형 버튼 크기, 종료 버튼 위치는 유지한다. 서버·API·음성·Android 로직은 변경하지 않는다.

원인: 공통 설정 toolbar가 52px를 사용하고, 통화 상단 여백(40/80px)·헤더 아래 24px가 큰글씨에서도 남아 있다. 본문 폰트와 하단 설명 줄수는 늘었으므로 카드가 작아진다.

- [x] 실제 문제 크기(400×688)와 390×844, 320×568에서 기본/큰글씨 카드 높이와 종료 원 위치를 측정하는 실패 테스트 추가.
- [x] Preact 공통 표시 설정 context를 사용하여 모드와 설정을 공통 toolbar에 배치. 대화상자/입력/세션 컴포넌트는 재생성하지 않는다.
- [x] 큰글씨 Agent 화면에서만 위 여백/헤더 간격을 축소하고 남은 높이를 카드에 배정. 짧은 화면에서도 번호·시간을 읽을 수 있게 유지.
- [x] 기존 웹 행동 테스트와 새 배치 테스트 통과, 기본 글씨 배치 보존과 source→generated 일치 확인.
- [x] 로컬 브라우저에 개선 화면을 열고 전/후 이미지 제공. 공유 브랜치와 배포판은 수정하지 않고 작업 브랜치에만 반영.


## 검증 결과
- 실제 사용 중인 창 327×688에서 Noto Sans KR/Gowun Batang을 로컬 제공하여 후보 3개가 카드 안에 보임을 검증했다. 폰트를 차단한 기본 대체 글꼴만으로는 이 줄바꿈 문제를 재현할 수 없어 실제 폰트 입력을 테스트 서버에 추가했다.
- 큰글씨 Agent의 좌우 바깥 여백은 20→12px, 카드 패딩은 16→12px. 위 여백과 헤더 간격을 줄이고, 번호/기관/시간은 자연스럽게 줄바꿈하는 헤더로 정리했다. 폰트와 원형 버튼 크기는 유지했다.
- 웹 전체 행동 테스트: 실제 폰트 포함 18 passed. 327×688, 400×688, 390×844, 320×568 및 데스크톱 포함.
- 기본 글씨의 카드/toolbar/종료 및 보조 버튼 사각형을 변경 전 커밋과 비교: 400×688, 390×844, 320×568에서 동일했다.
- 종료 원의 크기는 동일하며 큰글씨 전환 전후 y 차이는 3px 이내(기존 글자 높이 차이)로 유지한다.
- 짧은 화면 입력 DOM 유지, 종료 화면 번호 중복, 일반 전화 번호 보존, 긴 번호 줄바꿈, 설정 복원, API 차단을 검증했다.
- source→static 재생성 결과 일치, diff 공백 검사 통과, Python 서버 파일 변경 없음. 기존 Python suite의 이미 확인된 실패는 이 웹 배치와 무관하여 수정하지 않았다.
- 별도 읽기 전용 코드 검토에서 추가 Critical/Important 지적 없음. 최신 기준 브랜치 HEAD는 0871ac60으로 동일했다.
- Ruling: 폭이 좁을 때 큰글씨 카드의 가로 여백도 줄여 실제 폰트에서 제목과 선택지가 읽히도록 했다. 기본 글씨 여백은 유지한다.
