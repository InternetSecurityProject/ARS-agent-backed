# 기다림·응답 화면 구분 — 승인된 로컬 범위

- 기준 c573932. 기존 작업 폴더에서 웹만 변경하며 푸시·머지·서버 배포는 사용자 화면 확인 뒤 별도 승인까지 하지 않는다.
- 진행 중에는 ‘기다려 주세요’와 ‘원하는 메뉴를 찾고 있어요’를 표시한다. 연결 전·상담원 대기·결과·오류는 실제 상태에 맞는 기존 제목을 유지한다.
- 응답은 서버 질문 원문을 제목으로 표시한다. 개인정보는 기존 입력 항목 제목과 카드 밖 키패드를 유지한다.
- 응답 가능한 카드만 은은한 파란 테두리를 유지하고 새 요청마다 한 번 짧게 강조한다. 전송 후·만료·연결 오류 시 강조를 해제한다. 모션 감소 설정을 존중한다.
- 기존 음성·개인정보 제한·전송·기한·중복 전송 방지는 그대로 재사용한다. 새 음성 안내나 AI 요약은 만들지 않는다.
- 데모와 큰글씨에도 적용한다. 배경·폰트 크기·키패드·하단 버튼 위치는 유지한다. 후보 확대·경로 접기 등 2~6번은 제외한다.
- 접근: 공통 화면 표현 상태를 읽기 전용으로 도출하고 기존 카드에 스타일을 붙인다. 별도 화면 전환이나 카드 remount는 입력·음성 유지에 불리하므로 사용하지 않는다.
