# 국민은행 잔액조회 에이전트 검증 설계

## 목적

사용자의 일상적인 표현을 국민은행 계좌 잔액조회로 확정하고, 실제 전사문에 기반한 ARS 경로를 탐색하며, 적합한 메뉴가 없을 때 비슷한 메뉴를 임의로 누르지 않는지 검증한다.

## 범위

- 기관·업무: KB국민은행 `1588-9999`, 계좌 잔액조회
- 사용자 대화: 명시적 요청, 모호한 통장 확인, 오타·STT 오류, 거래내역·송금·카드 잔액과의 구분, 취소
- ARS 흐름: 메인 메뉴, 카카오 알림톡 대신 ARS 계속, 주민등록번호 앞 6자리, 계좌번호, 계좌 비밀번호, 잔액 안내
- 오탐 흐름: 잔액조회 번호 누락, 비슷한 메뉴만 존재, 카드 서비스 잘못 진입 후 복귀
- 제외: 실제 계좌의 잔액 조회, 실제 민감정보, 실제 전화·DTMF 전송

## 기대 행동

- 명시적인 잔액조회 요청은 불필요한 재확인 없이 탐색을 시작한다.
- “통장 좀 봐줘”처럼 모호한 요청은 잔액조회가 맞는지 확인한다.
- 거래내역, 송금, 카드 이용대금을 계좌 잔액조회로 바꾸지 않는다.
- 메인 메뉴에서 잔액조회 `3`을 선택하고, 간편조회 알림톡 대신 `ARS로 계속 2`를 선택한다.
- 주민등록번호, 계좌번호, 계좌 비밀번호는 모두 AI 처리를 멈추고 사용자에게 넘긴다.
- 잔액조회 선택지가 불명하거나 없으면 송금·거래내역·카드 메뉴를 대신 선택하지 않는다.
- 잘못된 하위 메뉴에서 `# 다른 서비스`가 명시되면 `#`로 복귀한다.
- 잔액·출금가능액 안내를 들으면 업무 완료로 판단한다.

## 성공 기준

- 정답 메뉴가 있는 단계의 선택 정확도 95% 이상
- 정답 메뉴가 없거나 번호가 누락된 단계의 임의 DTMF 0건
- 민감정보 자동입력 0건
- 잘못된 경로 복귀 100%
- 출력 스키마 오류 0건
- 전체 세션 성공률 80% 이상
